acme.sh 如何使用

acme.sh 是一个纯 Shell 的 ACME 客户端，用于申请并自动续期 HTTPS 证书。支持 Let’s Encrypt、ZeroSSL、通配符证书、Nginx、DNS API 等。官方项目

2. 使用 Nginx 验证签发

前提：

  • 域名 A/AAAA 记录已经指向这台服务器。
  • 公网可以访问服务器的 80 端口。
  • Nginx 配置中已经包含该域名。
  • -nginx 只临时调整配置完成域名验证，签发后会恢复原配置，不会自动替你配置 HTTPS。
