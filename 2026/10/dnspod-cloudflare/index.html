通过cloudflare和dnspod实现网站分流

通过 DNSPod 与 Cloudflare 实现网站国内外流量分流，核心逻辑是利用 DNSPod 的智能分线解析功能，将国内与国外的访客引向不同的线路和节点，从而实现“国内直连/国内CDN加速，国外走Cloudflare CDN代理”。 1, 2

你可以参考以下完整流程和实施步骤：

一、 核心原理解析

  1. 国内流量：通过 DNSPod 解析到你的国内源站、国内CDN 或优化路线 VPS，保证国内访问速度。
  2. 国外流量：通过 DNSPod 智能解析为 CNAME 指向一个中间域名（托管在 Cloudflare 上并开启 Cloudflare for SaaS），由 Cloudflare CDN 全球节点进行代理加速。 1, 2, 3

二、 前期准备工作

• 主域名：托管在支持智能分流的 DNS 服务商（如 DNSPod）。
• 备用/中间域名：另外准备一个辅助/中转域名（托管在 Cloudflare 上）。
• 源站服务器：一台国内/优化线路的主服务器，以及 Cloudflare 账号。
• 支付验证：Cloudflare for SaaS 功能可能需要绑定 PayPal 或信用卡（免费额度内不扣费）。 1, 2

三、 配置步骤

第一步：配置 Cloudflare 回退源与自定义主机名

  1. 登录 Cloudflare，进入你的中间域名控制面板。
  2. 配置 SSL/TLS 设置。
  3. 在 Cloudflare for SaaS 功能中，设置回退源（Fallback Origin），将其指向你的主服务器 IP 或源站地址。
  4. 添加你的正式主域名作为自定义主机名（Custom Hostname），并根据提示添加 TXT 记录完成所有权验证。 1, 2

第二步：在 DNSPod 配置智能分流解析

  1. 登录 DNSPod（腾讯云解析），找到你的主域名。
  2. 添加解析记录，利用 DNSPod 的按区域解析（智能分线）功能：
    • 国内线路（如中国大陆）：记录类型设为 A 或 CNAME，直接指向你的国内服务器 IP 或国内 CDN 加速域名。
    • 国外线路（如境外）：记录类型设为 CNAME，指向你在 Cloudflare 配置好的中间域名。
    • 默认线路：可以根据需求指向国内或国外。 1, 2

第三步：测试与验证

  1. 使用国内的在线测速工具或多地 Ping 工具，检查国内 IP 解析出来的是否为你的国内源站/国内CDN。
  2. 使用国外的测速工具（如 Ping.pe 或海外节点），检查解析出来的是否为 Cloudflare 的 CDN 节点 IP。 1, 2
